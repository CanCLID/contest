# Contest

粵拼打字比賽嘅純前端 demo，用嚟試輸入流程同討論賽規。正式需求同實現計劃見 [SPEC.md](SPEC.md)。

**試玩：[粵拼競速 demo](https://canclid.github.io/contest/)**

## Demo 有乜

- 揀「自由練習」就係原本嘅單篇玩法：首頁先顯示試玩設定，按「開始試玩」先顯示題目、計時同成績；取消本輪就返設定，完成後保留結果。
- 主入口預設「官方三輪試玩」流程：第 1 輪落石單字 90 秒、第 2 輪詞鏈詞組 120 秒、第 3 輪幽靈競速篇章計時（內建 55 音節／分示範幽靈陪跑，純氣氛，唔影響計分），三輪順住連打；每輪完場自動寫入流程狀態再跳去下一輪，最後一頁係本機三輪成績卡（逐輪計分窗／用時、正確／已交、準確度、正式分、門檻達標）。流程狀態只存喺 sessionStorage，完成紀錄存 localStorage（最近 20 次）。想玩返原本嘅單篇玩法，喺設定卡揀「自由練習」（揀咗先展開單篇同小遊戲入口面板），或者由遊戲大廳「單篇練習」卡（帶 `?practice=1`）返嚟就會預設揀好。
- 官方三輪只係本機試玩：三輪總分排名仍然要正式比賽由伺服器按組內中位數標準化結算；成績卡亦會寫明呢一點。
- 開賽後收起設定表單，賽場上方用純文字資料卡顯示本輪暱稱、組別同文章。完場後可以沿用設定再玩，或返回設定頁修改。
- 選擇手機組或電腦組，打完同一篇原創示範粵文，以實際完成用時鬥快，唔設固定計分時限。
- 直接喺文章上逐音節輸入無聲調粵拼，自己輸入嘅字母顯示喺漢字上方，當前字有底線／高亮；冇獨立可見文字框。空白鍵或 Enter 提交，非空答案對錯都會前進。
- 答案只接受 A–Z／a–z 英文字母，統一轉成小寫。電腦組直接讀文章區嘅按鍵；輸入法未提供英文字母時，嘗試用 KeyA–KeyZ 實體鍵碼取得字母。手機仍使用原生系統鍵盤並過濾字元，網站無法保證所有輸入法切到英文，亦唔會由中文組字結果猜返字母。
- 開始或點文章就聚焦輸入，手機使用系統鍵盤。當前音節有字母時，Backspace 正常刪字；空白時可退回上一個已提交音節，恢復舊答案重編，亦支援跨句退回。
- 提交最後一個音節就自動完場，答案及時間凍結；修正、閒置同切頁所用時間都計入。
- 手機使用系統螢幕鍵盤，介面保持簡潔。手機組禁止外接鍵盤，但唔做硬件偵測；組別由參加者自行確認。
- 顯示完成時間、總輸入速度、準確度、試算綜合分同本機成績；本機榜列正式分（正確音節／分鐘 × 準確度，未達 85% 門檻標示）同試算綜合分，榜單按組別、文章版本同規則版本隔離。
- 聲母、韻腹同韻尾各自顯示準確率格仔：灰色未輸入、綠色全啱、紅色全錯、橙色有啱有錯。按現存已提交答案統計，撤回改錯會同步重算；滑鼠提示顯示正確次數同錯誤率，唔影響整字計分。
- 試玩時可以開關「粵拼提示」，本句所有字同下一句預覽都會直接喺中文字上方顯示完整、無聲調嘅 ruby 註音；轉句後繼續顯示。提示同輸入共用同一行，灰色提示打啱後原位變黑。錯答按聲母／韻母標出綠色正確部分同紅色刪線錯誤部分，例如 `bui` 打成 `bei` 會保留黑色 `b`，並顯示綠色 `ui` 同紅色刪線 `ei`。唔自動填答案，亦唔暫停計時；每輪預設關閉。
- 本輪一旦開過提示就標為「用過提示」，關閉後仍保留。完場紀錄另按最近完成排列，唔參與無提示排名；兩類合共保存最近 20 輪，舊版冇提示功能嘅紀錄沿用無提示分類。
- 界面支援繁體粵語（預設）同簡體粵文雙語：系統語言係簡體中文（zh-CN／zh-SG／zh-Hans）就自動顯示簡體粵文，其他（繁體／英文）顯示繁體；header 右上角有切換掣可以隨時轉，選擇記喺 localStorage（`canclid-contest-locale`）。靜態文案（`data-i18n`）同動態文案（`t()`）都會跟住換，簡體只改字形，粵語詞彙語法照舊。
- 小遊戲大廳喺 [demo/games/](demo/games/)，係練習模式集中地，有五張免登入嘅卡：「粵拼落石」60 秒內喺石頭落地前打出石上單字（可計分）、「粵拼詞鏈」用 seed 抽 20 個詞逐個音節打（可計分）、「幽靈競速」同自己最佳時間線或內建示範幽靈鬥快打完全篇示範文章（可計分，另設「淨計時」唔設對手）、「聲韻解鎖塔」逐層解鎖聲母／韻腹／韻尾嘅自適應練習（練習，唔排名）、「單篇練習」返試玩賽場嘅單篇自由練習（帶 `?practice=1`）。官方三輪試玩係主站主線流程，唔屬於大廳，大廳有提示條連返試玩賽場開始。試玩賽場設定卡用兩張全寬選項卡揀「官方三輪試玩」或「自由練習」；揀自由練習先展開面板，可以喺本頁開始單篇練習，或者經四個小遊戲捷徑同大廳入口去對應模式（捷徑唔帶 `flow=1`）。成績只存本機。

準確度按最後保留答案計算：正確音節 ÷ 已提交音節。撤回唔會永久保留舊錯誤，但修改所花時間照計。總輸入速度係已提交音節 ÷ 實際用時分鐘數。本機單篇榜按正式分排名：**正式分 R ＝ 正確音節／分鐘 × 準確度（SPEC §5.5 已確認方向）**，未達 85% 篇章門檻會標示；同分先比準確度、再比完成時間，全部相同就並列。demo 試算綜合分「速度 × 準確度比例²」另列喺榜上，只作新舊紀錄比較。三輪總分以組內中位數標準化分（0.3／0.3／0.4）加權合成，由正式賽伺服器計算。

示範榜單同本機成績分開標示。Demo 未有帳戶登入、後端、真正多人同步或可信嘅比賽排名；選組亦唔係裝置認證。正式粵文文章由用戶稍後提供，文章字數未定。

使用原創題目及系統字體，冇外部腳本、字體或分析追蹤請求。本機紀錄最多保存最近 20 輪；儲存不可用時會留喺當前頁面記憶體。舊版紀錄唔同新版文章完成賽制混排。

## 本機試用

喺 repo 根目錄執行：

```sh
python3 -m http.server 4173 --directory demo
```

用瀏覽器開 [localhost:4173](http://localhost:4173)。測試用 Node.js 執行，毋須安裝依賴：

```sh
npm test
```

215 項自動測試涵蓋提示逐字母變黑、聲母／韻母改錯對照、缺字及多打字母、Backspace 修正、多讀法及長錯答、手機字格換行後輸入位置、本句及下一句註音、提示開關與草稿／選取／IME 保留、用過提示標記及紀錄分類、首頁與本輪資料切換、沿用設定重玩、分項準確度、「茶」接受 `caa`、重複輸入事件、焦點恢復、跨句撤回、計分、完場凍結及本機紀錄保存；另加四個小遊戲模式嘅測試（落石 40、詞鏈 25、幽靈競速 21、聲韻解鎖塔 13，各有純邏輯、頁面骨架同 DOM 流程測試）、官方規則預演 18 項、官方流程狀態同路由 12 項、三輪成績卡 9 項。主入口 35 項測試跟住新資訊架構更新：撳「開始試玩」預設開三輪流程、`?practice=1` 同設定卡「自由練習」選項卡會預設揀單篇練習（揀官方三輪收埋練習面板）、玩法頁六張卡、排行榜正式分欄同 85% 門檻標示，另有高頻 tick 只喺數字有變先寫 DOM 嘅防跳動測試；`?flow=1` 篇章輪鎖定內建 55 音節／分示範幽靈陪跑。雙語界面另有自動測試：i18n 運行庫（偵測簡繁、setLocale 寫 storage、非法值拋錯、`data-i18n`／`data-i18n-placeholder` 切換同還原、切換掣綁定同事件）同主站切換掣來回轉語言（靜態文案、動態文案、`documentElement.lang` 同步，預設無設定時保持繁體）。較早版本已用瀏覽器驗證輸入及提示紀錄流程，以及 320／390px 版面；今次新增嘅官方流程、成績卡同版面改動因 Work 設定停用本機瀏覽器操作，只做過 `python3 -m http.server` 資源檢查同自動測試，未能重新驗證實際排版。iOS／Android 真機鍵盤兼容亦尚未測試。已知限制：iOS 會按 App 記住上次手動切過嘅鍵盤語言（Safari 內曾手動切去中文鍵盤，之後連 `lang="en"` 嘅輸入框都可能繼續顯示中文鍵盤）；遇到時喺鍵盤上按地球鍵切返英文，或者重開 Safari 就得。

## GitHub Pages

**已上線：[https://canclid.github.io/contest/](https://canclid.github.io/contest/)。** CanCLID/contest 已按用戶批准改為 public。

Pages 已設為 GitHub Actions 部署。之後更新 demo 並 push 後，喺 Actions 手動執行 **Deploy demo to GitHub Pages**。流程會先跑測試，只將 `demo/` 上傳為網站；repo 本身嘅文件同 Git 歷史亦已公開。Push 本身唔會觸發部署。

2026-10-20 [首次部署成功](https://github.com/CanCLID/contest/actions/runs/39475288574)，已驗證線上輸入及 Backspace 修正，並確認六個網站資源均回傳 HTTP 200、內容雜湊同本機版本一致。

GitHub Pages 只供呢個靜態 demo；正式服務嘅阿里雲部署、手機短訊／Google 登入、全球約 2,000 人同場比賽及兩組獨立排名，仍按 [SPEC.md](SPEC.md) 規劃。
