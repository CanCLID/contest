# 粵拼打字比賽：遊戲化小遊戲設計調研報告

> 調研日期：2026-10-22。方法：子代理網絡調研（產品盤點 + 學術文獻 + 粵語生態產品）。
> 狀態：調研結論，供賽事方確認；已整理入 SPEC.md §3.3。

## 摘要（先講結論）

1. **「見字打音」必須係所有正式計分小遊戲嘅唯一方向。** 現存粵拼遊戲有一半係「見音打字」或「見字母猜字」（粵拼泡泡、Zidou、Lukhap 六合），呢啲練嘅係聽辨同拼寫，唔係比賽要嘅「由漢字提取讀音」。可以留作練習，唔可以入正式榜。
2. **單字適合高頻反應類（掉落消除、打地鼠、翻牌配對）；詞組適合連續輸入類（連擊、接龍、Boss 傷害）；篇章適合耐力／競速類（幽靈競速）。** 呢個分工同金山打字通「字母遊戲 → 單詞遊戲 → 長句遊戲」嘅經典設計完全一致。
3. **2000 人同場嘅硬約束決定咗唔可以做實時 PvP。** 按 SPEC 容量模型，2,000 人 × 每秒 2 次提交 = 4,000 訊息／秒；一旦廣播就會變成每秒 800 萬次投遞。所以小遊戲必須採用「同 seed、各自作答、非同步比併」模式，Boss 戰只可以用聚合計數器。
4. **純速度排名最易被腳本騎劫；應該沿用內地跟打圈嘅成熟做法**：速度 = 擊鍵 ÷ 碼長 × 60 ×（1 − 回改率），並記錄鍵準、回改率、重打次數。呢套指標可以直接翻譯成粵拼版本。
5. **連擊（combo）同每日挑戰係雙面刃**：連擊提升節奏感但放大隨機性同鼓勵亂打；每日挑戰答案會外流（Wordle 類遊戲已有先例），只可以做社群預熱。

## 前提：項目已定規則對小遊戲嘅限制

| 已定規則 | 對小遊戲設計嘅影響 |
|---|---|
| 每次提交一個音節；對錯都前進；Backspace 可退回 | 遊戲原子動作 = 「打一個音節 + 空格」。所有機制必須建基於此，唔可以設計「打錯就卡住」嘅玩法 |
| 答案只接受 A–Z、無聲調 | 任何含數字（聲調）、標點、選擇題嘅玩法都要改造 |
| 手機組只用系統鍵盤、介面簡潔 | 唔可以要求快速多目標切換；亦唔可以自製遊戲內鍵盤 |
| 2,000 人同場、分組排名 | 即時同步類玩法（實時賽車、PvP 攻擊）成本不可接受 |
| 正式場唔提供答案提示、唔提供讀音播放 | 聽音類玩法（粵拼泡泡式）只能做練習 |
| 答案可喺前端讀取，唔作可信賽事裁判 | 所有遊戲都要設計伺服器覆核路徑 |
| 已有聲母／韻腹／韻尾三行準確度統計 | 呢個係現成嘅「弱項資料」，可以驅動自適應練習 |

## B. 題型 × 機制適配分析

### B1. 單字（1 音節／目標）

**本質**：每次互動資訊量最小、頻率最高、可以大量重複。練嘅係「字形 → 讀音」嘅即時檢索速度。

| 機制 | 適合？ | 理由 |
|---|---|---|
| 掉落消除（落石／蘋果／燈籠） | ✅ 最適合 | 每個目標獨立、對錯即時可見、天然支援大量重複；手機單一目標流操作順暢 |
| 打地鼠／氣球 | ✅ 適合 | 同上，節奏更輕快；缺點係目標出現隨機，較難控制題序 |
| 射擊（ZType 式） | ⚠️ 部分適合 | 需要「多目標並存 + 選擇」，觸控鍵盤上切換目標極困難；單目標版本可行 |
| 翻牌配對（字 ↔ 粵拼） | ⚠️ 只做練習 | 配對唔係打字；但可以用嚟做暖身 |
| 限時配對（Duolingo 式） | ❌ 唔適合 | 唔係打字，練唔到輸入 |
| 聽音打字 | ❌ 正式場唔可以 | 需要耳機 + 讀音播放，SPEC 已排除；練習場可留 |
| 連擊／combo | ✅ 適合 | 單字節奏快，連擊回饋感最強 |
| 關卡（自適應解鎖聲母／韻母） | ✅ 最適合 | 單字係唯一可以精準控制「練邊個聲母／韻母」嘅題型 |

**反作弊角度**：單字題目極短，答案容易被枚舉／腳本化，**必須靠提交時間戳分佈 + 重打驗證**，唔可以靠題目保密。

### B2. 詞組（2–3 音節／目標）

**本質**：中等長度，有內部結構（聲母 + 韻腹 + 韻尾），係「連續輸入唔斷」同「修正策略」嘅訓練場。

| 機制 | 適合？ | 理由 |
|---|---|---|
| 連續連擊（打完一個詞即刻出下一個） | ✅ 最適合 | 貼近正式比賽嘅連續輸入節奏，又比篇章短、可即時結算 |
| 接龍（尾音接頭音／同聲母） | ✅ 適合（粵拼專屬） | 逼玩家注意聲韻結構，係通用打字遊戲冇嘅玩法 |
| Boss 戰（每正確音節 = 傷害） | ✅ 適合 | 詞組長度令傷害累積有節奏；集體目標天然可擴展 |
| Wordle 式猜謎（六合／Zidou） | ⚠️ 只做社群功能 | 打字量極少、思考量極大，同「練輸入速度」目標相反；答案可分享 |
| 賽車競速 | ✅ 適合 | 詞組串可以當短篇章賽 |
| 卡片收集 | ✅ 適合（非排名） | 「粵語詞卡／諺語卡」係低成本高情懷嘅收集物 |
| 限時挑戰 | ⚠️ 要小心 | 詞組長度令「限時」嘅隨機性放大（抽到長詞就蝕底），需固定題序 |

### B3. 篇章（多句／多音節）

**本質**：耐力、節奏管理、修正取捨。已經係現有正式賽制。

| 機制 | 適合？ | 理由 |
|---|---|---|
| 幽靈競速（對自己／官方錄影） | ✅ 最適合 | 零廣播成本、零延遲爭議、可無限重玩；TypeRacer 已驗證 |
| 實時多人賽車（Nitro Type 5 人房） | ⚠️ 只可以小規模 | 2,000 人做唔到；但決賽／表演賽可以用小房間做 |
| Boss 合力戰 | ✅ 適合 | 篇章係傷害累積最自然嘅載體 |
| 掉落消除 | ❌ 唔適合 | 篇章冇「掉落」概念，強行改造會令節奏破碎 |
| 關卡 | ❌ 唔適合 | 篇章係完整作品，唔應該切碎 |

### B4. 跨題型：2000 人擴展性與反作弊

**擴展性三條紅線**

| 紅線 | 原因 | 對策 |
|---|---|---|
| 唔可以實時廣播每次提交 | 4,000 次／秒 × 2,000 人 = 800 萬次投遞／秒 | 改為「同 seed 各自作答」；只有 Boss 戰用聚合計數器 |
| 唔可以每下按鍵等伺服器 | 高延遲玩家會被拖慢，體驗崩壞 | 本地判定即時反饋 + 每局結束一次上傳提交序列，伺服器重算 |
| 唔可以依賴瀏覽器自報時間 | SPEC 已明確唔可信 | 每次提交記錄伺服器時間戳；速度用伺服器認定嘅首尾時間差 |

**反作弊：可以照搬內地跟打圈嘅成熟指標**

內地中文打字比賽（極速打字網「幻影杯」、添雨／極速跟打器）已經運行多年，佢哋嘅成績表有呢啲欄位：**速度、擊鍵、碼長、字數、時間、回改、鍵數、鍵準、重打、打詞、錯字、輸入法、設備**。核心公式：

```
速度 = 擊鍵 ÷ 碼長 × 60 × (1 − 回改率)
鍵準 = (總按鍵數 − 退格數 − 回改數 × 平均碼長) ÷ 總按鍵數
```

翻譯成粵拼版本：

| 跟打圈指標 | 粵拼版本 | 用途 |
|---|---|---|
| 速度（字／分） | 正確音節／分鐘 | 主指標 |
| 擊鍵 | 每秒按鍵數 | 偵測機械化輸入（真人鍵速有自然抖動） |
| 碼長 | 每音節平均字母數 | 粵拼約 3–4 字母，偏離即異常 |
| 回改 | Backspace 撤回次數 | 修正行為指紋 |
| 鍵準 | 字母級準確率 | 比「音節準確率」更難造假 |
| 重打 | 同一段重打次數 | 高分成績抽檢 |
| 設備／輸入法 | 裝置指紋 | 組別核查（非證明） |

**反作弊四層**：
1. **提交時間戳序列分析** — 機械化輸入嘅鍵距過於均勻（業界已有「keystroke timing analysis」做法）。
2. **重打驗證** — 高分成績要求以接近表現重打一段（TypeRacer 嘅 CAPTCHA 先例，要求以賽事 WPM 的 25% 內完成）。
3. **題目種子鎖定** — 同組同一 seed、同一題序，唔可以按各人弱項出唔同題（否則無法比較，亦方便挑軟柿子）。
4. **成績唔用純數量** — 用「正確音節 × 準確率²」（即現有試算公式）而唔係「打咗幾多個」，令亂打冇利可圖。

### B5. 遊戲化元素逐項評估

| 元素 | 對技能提升嘅有效性 | 對比賽公平性嘅影響 | 建議 |
|---|---|---|---|
| **關卡／等級** | 高（漸進難度係技能成長核心） | 高風險（各人關卡唔同，無法比較） | **只做練習模式**，唔入榜 |
| **連擊 combo** | 中（提升節奏感，但鼓勵求快） | 高風險（一個錯字清零 → 隨機性放大） | 可入榜但**必須設倍率上限**（例如 ×1.5 封頂） |
| **限時挑戰** | 高（逼出真實速度） | 中風險（需要固定題序才公平） | 用「固定時間盒 + 固定 seed」，兩組分開排名 |
| **掉落消除** | 高（單字反應訓練） | 中風險（本地判定 → 可腳本） | 本地判定 + 提交序列上傳覆核 |
| **賽車競速** | 高（貼近正式賽制） | 低風險（幽靈版）／高風險（實時版） | 只做**幽靈競速**，唔做實時多人 |
| **Boss 戰** | 中高（弱項專項訓練載體） | 集體目標低風險；個人傷害榜極高風險 | 集體目標入活動，個人排名用正確率而唔用傷害 |
| **每日挑戰** | 中（培養習慣） | 極高風險（答案會被分享，Wordle 類已有先例） | 只做社群功能，獎勵用「連續參與日數」 |
| **卡片收集** | 低（對技能無直接幫助） | 低風險（純外觀） | 做賽前預熱期嘅留存工具 |
| **道具／攻擊** | 低（技能外變數） | 極高風險 | **唔採用** |

**注意**：教育遊戲化研究顯示，徽章、競爭、排行榜、積分系統係最常導致負面效果（表現下降、作弊、動力下降）嘅元素（Almeida et al. 2023 系統性回顧 77 篇研究；Toda et al. 2018）。排行榜設計本身有學問（Park 2021），而打字本身存在速度—準確度取捨（Heitz 2014）——呢個正好解釋為何本項目已定「綜合分要兼顧兩者」係正確方向，而純速度排名係危險嘅。

## C. 推薦嘅六個小遊戲模式

### 模式 1：粵拼落石（單字 · 掉落消除）

**玩法**：畫面上方跌落石頭／燈籠／紙牌，每塊寫一個漢字。打啱該字嘅無聲調粵拼 + 空格，即刻爆開。漏接扣血（3 條命）。一局 60 秒，或固定 40 字。連續正確有 combo 倍率，**上限 ×1.5**。掉落速度以「目標／秒」定義。

**適用題型**：單字為主；進階版可以出雙字詞（2 音節／目標）。
**手機組**：✅ 可以。單一目標流，觸控鍵盤足夠；掉落速度用時間單位定義，令兩組難度一致。
**競賽性**：強。分數直接用「正確音節／分鐘 × 準確率²」接返現有公式，兩組分開榜。
**公平性風險**：中。答案在前端 → 可腳本化。對策：伺服器 seed 出題、本地判定、每局上傳提交序列（音節 + 相對時間），伺服器重算並檢查鍵距分佈；高分成績抽檢重打。

### 模式 2：粵拼詞鏈（詞組 · 連擊）

**玩法**：一次顯示一個雙字／三字詞（香港、唔該、士多啤梨），打完即刻出下一個。整個詞全對 +1 連擊層，連擊越高分越高（封頂）。有音節打錯唔會中斷（符合「對錯都前進」），但會斷連擊並扣分。一局固定 20 個詞。

**進階玩法（粵拼專屬）**：下一個詞嘅第一個音節，要同上一個詞最後一個音節「同聲母」或「同韻母」，逼玩家留意聲韻結構。

**適用題型**：詞組（2–3 音節）。
**手機組**：✅ 可以。節奏比落石慢，更適合觸控。
**競賽性**：強，而且比落石更貼近正式賽能力（連續輸入 + 修正取捨）。
**公平性風險**：中低。詞表固定、可以公開練習；正式場用未公開詞表。**連擊倍率必須封頂**，否則一個難詞就清零，隨機性過大。

### 模式 3：幽靈競速（篇章／詞組 · 賽車）

**玩法**：同現有篇章賽制一樣，但對手係「幽靈」：自己最佳紀錄、朋友、或官方種子（去屆冠軍、CanCLID 示範錄影）。幽靈按錄製時嘅音節提交時間軸重播，畫面上一齊跑。

**適用題型**：篇章（亦可以係固定詞組串）。
**手機組**：✅ 可以，同現有輸入介面完全一樣。
**競賽性**：強，而且係**最省伺服器嘅競技模式**——零廣播、零實時同步、零延遲爭議。
**公平性風險**：低。對手係錄影，唔受網絡影響。
**實作要點**：只需錄「（音節索引，相對開始時間）」序列，一篇 200 音節約 1.6KB。

### 模式 4：合力打「懶音獸」（單字／詞組 · Boss 戰）

**玩法**：全場 2,000 人一齊打同一隻 Boss，每提交一個正確音節 = 1 點傷害。Boss 分階段，每階段只收特定類型嘅字：

| 階段 | 目標弱項 | 例子 |
|---|---|---|
| 一 | n / ng / 零聲母 對比 | 你 nei vs 李 lei、我 ngo vs 哦 o |
| 二 | gw / kw | 廣 gwong vs 港 gong、國 gwok vs 各 gok |
| 三 | −n / −ng 韻尾 | 心 sam vs 生 sang |
| 四 | m / ng 成音節 | 唔 m、五 ng |

全服合力擊破，有集體通關畫面。

**適用題型**：單字（分階段弱項）+ 詞組（後段）。
**手機組**：✅ 可以。
**競賽性**：集體目標極強、個人排名弱。**建議唔設個人傷害榜，或只設「正確率榜」**——傷害量最易被腳本刷。
**公平性風險**：集體目標低；個人傷害榜極高。用聚合計數器 + 每 1–2 秒廣播一次全服摘要。
**學習價值**：最高。呢四階段直接對應香港常見懶音（PolyU 懶音診療室、公務員事務局教材）。**呢個係通用打字遊戲做唔到、粵拼獨有嘅賣點**。

### 模式 5：聲韻解鎖塔（單字／詞組 · 自適應關卡，非排名）

**玩法**：keybr 式。開局只開放部分聲母／韻母（例如 b, d, g, aa, i, u），達到「正確率 ≥95% 且速度 ≥ 目標」就解鎖新聲母／韻母；系統優先出玩家最弱嘅元件——**直接讀 demo 已經有嘅三行聲母／韻腹／韻尾統計**。

**適用題型**：單字（用真字，唔用偽音節）；詞組做整合練習。
**手機組**：✅ 可以。
**競賽性**：無。**明確唔入正式榜**（各人關卡唔同，無法比較）。
**公平性風險**：低。
**實作要點**：用現成統計資料，實作成本最低。適合做賽前 2–4 週推廣期嘅每日練習。

### 模式 6：每日粵拼謎 + 詞卡收集（詞組 · 社群功能，非排名）

**玩法**：Zidou／Lukhap 六合式：每日一題，六次機會猜一個詞嘅粵拼，顏色提示拆開聲母／韻腹／韻尾。完成後獲得「粵語詞卡」（諺語、口語字、地名、港鐵站名）。

**適用題型**：詞組。
**手機組**：✅ 可以。
**競賽性**：弱。**唔可以入正式榜**（答案會被分享）。
**公平性風險**：極高（答案外流）。獎勵只用「連續參與日數」而唔係分數。
**學習價值**：中高（練聲韻拆解），但係「見音猜字」方向，屬補充練習。**注意：唔可以當成正式賽嘅熱身**，因為方向相反。

### 唔建議採用嘅機制（同理由）

| 機制 | 唔採用嘅理由 |
|---|---|
| 實時多人賽車（Nitro Type 5 人房式） | 2,000 人做唔到；可以留作決賽／表演賽嘅小規模環節 |
| PvP 攻擊（打亂／凍結對手，KeyFight 式） | 網絡延遲直接變成勝負因素，公平性崩壞 |
| 道具系統（減速、護盾、炸彈） | 引入技能外變數，同「公平比拼粵拼能力」目標衝突 |
| 無限連擊倍率 | 隨機性放大；一個錯字清零唔公平 |
| 純速度排名 | 鼓勵亂打；且最易被腳本騎劫 |
| 聽音打字（粵拼泡泡式） | 需要耳機 + 讀音播放；SPEC 已定正式場唔提供。可留練習 |
| 堆疊式消除（Typing Tetris） | 需要「打錯就堆疊」，同「對錯都前進」規則衝突 |
